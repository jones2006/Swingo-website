# 🪢 SWINGO

> A playful desktop companion with playable charms, real-time physics, and interactive controls.

SWINGO is a Windows desktop companion that brings interactive characters to your desktop.

The idea started from a simple question:

**Why should desktop characters just sit there? 👀**

We wanted to build something where characters can actually **hang, swing, move, and react to user interaction and gravity**.

SWINGO is available on the Microsoft Store, and we continue to explore ways to improve the desktop companion experience.

---

## ✨ What is SWINGO?

SWINGO lets you add playful charms to your desktop and interact with them.

Instead of being just a static wallpaper or image, the charms are designed to feel more alive through real-time interaction and physics.

### Current interaction ideas

- 🪢 Hang from the desktop
- 🖱️ Drag and interact
- 💨 Swing with momentum
- 🔄 React to movement
- 🌍 React to gravity
- 🎨 Choose different charms

---

## 🖥️ Features

### 🪢 Playable Charms

Choose a charm and interact with it directly.

### ⚙️ Customization

Select different characters and personalize your desktop companion.

### 🌀 Real-Time Physics

The charms use physics-based movement to simulate:

- Gravity
- Momentum
- Rotation
- Drag interaction
- Rope movement

### 🔒 Windows Controls

SWINGO includes desktop-focused controls and interaction ideas such as:

- Windows Lock
- Lock Screen
- Screenshot / Snap
- Volume Mute

## 🪽 Meet WingGo — The Mobile Companion

> From desktop companions to mobile companions. 💙

SWINGO started as a way to bring playful, interactive characters to Windows desktops. That idea inspired us to explore a similar experience on Android.

**WingGo** is an Android mobile companion featuring a cute virtual flying mascot designed to bring a little personality to your phone.

While SWINGO focuses on desktop charms and physics-based interactions, WingGo explores floating companions, touch interactions, and native Android functionality.

### ✨ WingGo Highlights

- 🪽 An animated flying mascot
- 📱 A floating companion overlay
- 👆 Touch and gesture interactions
- 🔔 Native Android notification reactions
- 🔐 Google sign-in and guest access

### 🛠️ Built With

- React Native
- Expo
- TypeScript
- Kotlin
- Native Android APIs

WingGo is being developed as a separate Android project, exploring how a virtual companion can interact with a mobile device.

### 📦 Explore WingGo

- **Repository:** [WingGo on GitHub](https://github.com/jones2006/winggo)
- **Platform:** Android

> WingGo is a work in progress. Feature availability may vary depending on the current build and device.

## 🎨 The Idea

SWINGO started from a random reel.

While scrolling through reels, we came across a video showing small charms hanging from a MacBook.

We started looking into the concept and realized that this kind of experience was mainly available for MacBooks.

That got us thinking:

**"Why not build something for Windows?"**

So we decided to build our own desktop companion.

Later, we started exploring another question:

**"What if a virtual companion could live on your phone too?"**

That idea led to WingGo — our exploration of interactive virtual companions on Android.

Two platforms, one playful idea. 🪢🪽
