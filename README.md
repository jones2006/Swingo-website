# 🪢 SWINGO

> A playful desktop companion with playable charms, real-time physics, and interactive controls.

SWINGO is a Windows desktop companion that brings interactive characters to your desktop.

The idea started from a simple question:

**Why should desktop characters just sit there? 👀**

We wanted to build something where characters can actually **hang, swing, move, and react to user interaction and gravity**.

SWINGO is currently **under development**. 🚧

---

## ✨ What is SWINGO?

SWINGO lets you add playful charms to your desktop and interact with them.

Instead of being just a static wallpaper or image, the charms are designed to feel more alive through real-time interaction and physics.

### Current interaction ideas

- 🪢 Hang from the desktop
- 🖱️ Drag and interact
- 💨 Swing with momentum
- 🔄 React to movement
- 🌍 React to gravity
- 🎨 Choose different charms

---

## 🖥️ Features

### 🪢 Playable Charms

Choose a charm and interact with it directly.

### ⚙️ Customization

Select different characters and personalize your desktop companion.

### 🌀 Real-Time Physics

The charms use physics-based movement to simulate:

- Gravity
- Momentum
- Rotation
- Drag interaction
- Rope movement

### 🔒 Windows Controls

SWINGO is also being designed with useful desktop controls such as:

- Windows Lock
- Lock Screen
- Screenshot / Snap
- Volume Mute

## 🎨 The Idea

SWINGO started from a random reel.

While scrolling through reels, we came across a video showing small charms hanging from a MacBook.

We started looking into the concept and realized that this kind of experience was mainly available for MacBooks.

That got us thinking:

"Why not build something similar for Windows?"

So we decided to build our own version for Windows desktops.

And that's how SWINGO started. 🪢
